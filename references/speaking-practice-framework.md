# 口才训练框架 — 由术转道

> 为财税顾问量身定制的口才训练方法论。基于《刻意练习》+《即兴演讲》+ 十脉融合。

---

## 核心原则

1. **先写再录再说** — INTJ的习得路径是先输入再输出。不要直接上台，先在纸上写下来。
2. **三天一个反馈循环** — 练→录→听→改→再录。没有反馈的练习是浪费时间。
3. **不跟别人比，跟昨天的自己比** — 录音存好，一周后对比，进步自然会显现。
4. **一道破万术** — 不是你话术不够多，是你内核不够厚。十脉和道域才是底气来源。

## Day 1-4 结构（作为起点）

| 天 | 内容 | 交付物 |
|:---|:-----|:-------|
| Day 1 | 建立基准线：读三段完整话术，录下来 | 录音 + 自检5问 |
| Day 2 | 一句话抓手：4种开场×3遍 | 12句录音 + 改写版 |
| Day 3 | PREP结构：观点→理由→例子→观点 | 三段PREP录音 |
| Day 4 | 应对棘手问题：承认→架桥→重塑 | 三段回应录音 |

## 三种话术原型

适用于财税顾问的三种核心对话场景：

### 场景A：发现风险（预警式）
**结构**：陈述事实 → 点出风险 → 给出建议 → 征求同意
**示例**："张总，账上有一笔388万半年没动。钱在外面这么久，万一对方出问题就回不来了。我建议咱们先搞清楚这笔钱的性质，该催的催。您看行不行？"

### 场景B：客户压价（价值展示式）
**结构**：理解对方 → 转换视角 → 展示价值 → 缩小选择
**示例**："您觉得贵，我理解。但您选的不是价格，是结果。我们做过的类似方案，帮客户省了XX万。您要的是一个便宜的服务，还是一个能帮您省钱的方案？"

### 场景C：客户犹豫（紧迫感式）
**结构**：承认犹豫 → 制造对比 → 指向行动
**示例**："您想再等等，我理解。但等什么呢？等政策变好？等税务局先来查？还是等自己准备好？三种等法结果完全不一样。"

## 自检清单（每练必做）

1. 这段录音说了几个"嗯""呃""那个"？
2. 听起来像在念课文还是像在跟人说话？（1-10打分）
3. 如果你是老板，听到第几句会想打断？
4. 三段里面哪段最顺？为什么？
5. 明天再录一遍，想改进哪一点？

## 用锦书发布到公众号

写完话术脚本后，可通过 Jinshu MCP 渲染成公众号 HTML：

1. 写 Markdown
2. 调用 `render_wechat`（选主题如"极简黑"或"姹紫"）
3. 生成预览链接（手机确认效果）
4. 复制HTML → 粘贴进公众号编辑器 → 发布
