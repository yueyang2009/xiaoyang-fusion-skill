# 小企业会计准则：坏账损失科目归属（常见误区纠正）

## 背景

《小企业会计准则》（财会〔2011〕17号）内部存在正文与附录的口径不一致，导致实务中常见错误。

## 正确口径（附录+教材+实务统一口径）

### 核销坏账
```
借：管理费用（坏账损失）
  贷：应收账款
```
**不是**营业外支出。

### 收回已核销坏账
```
借：银行存款
  贷：管理费用（或红字冲减管理费用）
```
**不是**营业外收入。

## 为什么会有"营业外支出"的说法

准则正文第十一条确实写的是"计入营业外支出"，但附录（会计科目和主要账务处理）将坏账损失列在"5601 管理费用"科目下。

财政部后来的培训和全国初级会计职称考试教材统一到**管理费用**口径。

## 影响损益吗？

不影响最终结论——核销当年减利润、收回当年加利润，跨年分别影响各年未分配利润，净效果为零。

## 企业会计准则 vs 小企业会计准则

| 业务 | 企业会计准则 | 小企业会计准则 |
|------|-------------|---------------|
| 计提 | 借：信用减值损失 贷：坏账准备 | 不计提 |
| 核销 | 借：坏账准备 贷：应收账款 | 借：管理费用 贷：应收账款 |
| 收回 | 恢复应收账款+冲回准备 | 借：银行存款 贷：管理费用 |
