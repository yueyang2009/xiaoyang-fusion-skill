# 首次进场座谈原则（基于驰能电力实战提炼）

> 2026-06-21 确立 · 驰能电力座谈会后综合修正

## 核心原则

1. **第一问定乾坤**：开场必须是"马总，您希望我们帮您达到什么效果？一年以后您希望公司是什么状态？" —— 让老板自己说，他说什么就是服务的主线
2. **代账数据不可靠**：代账做的账大概率不反映真实情况，盯着账面细节问没有意义。第一次见面老板说的话比账上每笔数都重要
3. **先宏观再微观**：先对齐期望 → 再听老板说生意 → 最后摸底现状。千万不要上来就追资金占用、异常借款等账面疑点
4. **多听少说**：老板说话的时长应该占80%以上，你的任务是引导不是展示
5. **不追细节**：账面疑点不等于事实，老板没提之前不要追
6. **收尾定节奏**：座谈结束前确认两件事——我们下一步重点做什么、下次什么时候见面

## 优先级排序

```
第1步 对齐期望 ← 最重要！先问老板想要什么效果
第2步 听老板说生意 ← 让他讲，你听着，判断他的关注点和数字敏感度
第3步 摸底现状 ← 谁管钱、谁做账、税局找没找过
第4步 收尾确认 ← "您觉得我们最先从哪入手？"
```

## 禁止行为

- ❌ 不要追着代账数据问"为什么有421万资金占用"
- ❌ 不要用审计审问式语气（"为什么"→改为"想了解一下……"）
- ❌ 不要用emoji/图标，飞书无法正常显示
- ❌ 不要在第一次见面就试图把所有问题搞清楚

## 核心理念

> 第一次进场的唯一KPI是"让老板愿意约第二次"。问题没问完没关系，气氛不能搞僵。
