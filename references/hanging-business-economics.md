# 资质挂靠业务经济逻辑

> 被挂靠方（公司）提供资质，挂靠方实际施工/提供服务。
> 本文件记录双方的财务关系和成本承担规则，用于挂靠项目盈亏测算和顾问咨询。

## 业务主体关系

| 角色 | 说明 | 示例 |
|:----|:-----|:-----|
| **被挂靠方（公司）** | 提供资质、开发票给甲方、收管理费 | 吉诚电力 |
| **挂靠方** | 实际施工/做项目、承担税费、支付管理费 | 挂靠的个人/小团队 |

## 资金流向

```
甲方 → 被挂靠方（公司） → 交税（给税局）→ 扣管理费 → 余额给挂靠方
```

## 税费承担规则

### 1. 总税费：挂靠方承担

**所有税费（增值税+附加税+印花税+工会水利+企业所得税）由挂靠方承担。**
被挂靠方（公司）只是代缴主体，不承担税费成本。

### 2. 公司成本：仅限超标的所得税部分

企业所得税按 **2%** 预收（作为挂靠管理费的一部分）。
如果实际计算的应交企业所得税超过 2% 预收额，**超出部分才是被挂靠方的成本**。

```
公司成本 = MAX(0, 应交企业所得税 - 合同额×2%)
公司净利润 = 应收管理费 - 公司成本
```

### 3. 举例说明

**场景**：合同额100万，9%税率，52.5%抵扣比例

| 项目 | 金额 |
|:----|:----|
| 应交企业所得税（实际计算） | 2.5万 |
| 预收企业所得税（2%） | 2万 |
| **公司承担的超支税费** | **0.5万** |
| 应收管理费（一次性1%） | 1万 |
| **公司实际净利润** | **1万 - 0.5万 = 0.5万** |

## 测算工具中的展示逻辑

| 行项 | 说明 | 计算公式 |
|:----|:-----|:---------|
| 本次应收管理费 | 被挂靠方的收入 | 一次性=合同额×1%，长期代理=3万/年 |
| 公司超支的挂靠税费 | 被挂靠方的成本 | MAX(0, 应交企业所得税 - 合同额×2%) |
| 本次挂靠业务净利润 | 被挂靠方的利润 | 应收管理费 - 公司超支税费 |
| 盈亏平衡点最低挂靠费 | 挂靠方视角的参考值（总税费） | 增值税+附加税+印花税+工会水利+所得税 |

## 注意（咨询时跟老板说清楚）

- 税费挂在公司账上，税局找的是公司不是挂靠方——这是公司最大的风险敞口
- 管理费如果连超支所得税都覆盖不了，那就是亏本做挂靠
- 实务中公司往往还要垫资缴税（等挂靠方报销），这块资金成本不在测算内
