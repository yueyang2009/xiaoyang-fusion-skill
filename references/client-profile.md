# 客户画像

## 核心画像

年营收 **2000万-2亿** / 员工 **200人以内** / 总资产 **1亿以内** 的民营中小企业。

## 财务现状

- 财务不规范（代理记账或两套账）
- 无专业财务人员（老板亲戚/朋友兼职居多）
- 业务经营良好但账务混乱
- 老板不重视财务，图便宜找非专业人员

## 时代背景

金税四期上线，税务严征管时代。上下游企业陆续被查，合规意识被动或主动觉醒。不是企业快死了才来找我们——是企业想活更好、想规范才来。

## 方案铁律

1. 禁止使用"破产""资不抵债""倒闭"等不吉利词汇
2. 承认业务经营良好——根因是"财务投入不足"而非"经营失败"
3. 每个风险必须量化金额，不列数字老板不会行动
4. 涉税风险 vs 会计核算问题严格区分
5. 一次性出具，不自检迭代多个版本
6. 强调合规价值而非恐吓后果
