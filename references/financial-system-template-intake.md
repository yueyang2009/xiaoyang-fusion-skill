# 财务制度/流程手册类文件收编判断

用于用户投喂《财务流程手册》《财务制度大全》《岗位职责全套》等 Word/PDF 资料时，判断是否值得纳入小阳财税交付素材库。

## 快速结论口径

这类文件通常：

- **有参考意义**：适合当制度目录、流程清单、表单设计素材；
- **不宜直接交付**：模板痕迹重、行业错配、制度语言偏旧或偏大企业化；
- **最佳收编方式**：不收原文，收结构；不收大制度，收流程；不收处罚口吻，收老板能用、财务能执行的清单。

## 先做四项体检

1. **结构完整度**
   - 目录是否覆盖资金、报销、发票、合同、采购、销售、存货、固定资产、税务、档案、财务分析等模块。
   - 有无岗位职责、审批权限、表单附件。

2. **模板痕迹**
   - 搜索：`xxxx`、`某某公司`、`集团公司及各成员企业`、重复页眉页脚。
   - 出现大量占位符，说明不能直接给客户。

3. **行业错配**
   - 搜索明显行业词：如水价、水费、工程、门店、生产物料、会员、项目部等。
   - 行业词与目标客户不一致时，只能拆取通用流程。

4. **时代/合规口径**
   - 警惕旧口径：现金结算起点、过时税政、硬性罚款、加班式管理、过度行政处分。
   - 涉及税务、劳动用工、票据管理的内容必须按最新政策重写。

## 收编分层

### 第一层：制度目录框架库

保留目录，用作“中小企业财务制度体系清单”。常见模块：

- 资金管理
- 报销管理
- 发票管理
- 合同财务审核
- 采购与付款
- 销售与收款
- 存货管理
- 固定资产管理
- 成本核算
- 税务管理
- 会计档案
- 财务分析与经营报表

### 第二层：可交付制度模板库

拆成独立制度，不整本交付：

- 费用报销管理制度
- 付款审批管理制度
- 发票管理制度
- 合同财务审核制度
- 备用金管理制度
- 应收账款管理制度
- 会计档案管理制度
- 财务岗位职责说明书
- 采购付款流程
- 销售回款流程

### 第三层：轻量 SOP / 表单库

中小民企最实用的是表单和流程节点：

| 场景 | 可沉淀表单 |
|---|---|
| 报销 | 费用报销单、差旅费报销单、招待费审批单 |
| 付款 | 付款申请单、付款审批权限表 |
| 合同 | 合同财务审核清单 |
| 发票 | 发票签收登记表、发票异常处理表 |
| 备用金 | 备用金借款单、备用金核销表 |
| 应收 | 应收账款账龄表、逾期催收记录表 |
| 存货 | 入库单、出库单、盘点表 |
| 固定资产 | 固定资产卡片、资产盘点表、资产报废审批单 |
| 会计交接 | 会计交接清单 |
| 档案 | 会计档案归档清单 |

## 面向用户的评价模板

> 有用，但不能直接用。它适合当“制度素材库”，不适合当“客户交付稿”。建议拆、洗、轻量化，变成小阳财税标准财务制度包：目录框架 + 单项制度 + SOP表单。客户需要哪个模块就给哪个模块，不要甩一本厚制度。

## 交付建议

如用户要求继续加工，优先输出：

《财务制度素材收编清单-整理稿》

结构：

1. 模块名称
2. 是否保留
3. 保留原因
4. 需要删除/改写的内容
5. 适用客户类型
6. 可转化交付物：Word制度 / Excel表单 / SOP流程图
7. 优先级：高 / 中 / 低
