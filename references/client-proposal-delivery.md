# 客户财税风险方案交付准则

## 出方案→双审→修改→交付 流程

```
撰稿 → Codex硬审(法条/数据/合规) → Claude软审(语气/话术/承诺)
→ 汇总意见一次性修到位 → Word排版 → 存档知识库 → 交付
```

## 方案写作风格（老板版）

### 结构
```
🎯 这事像什么 → 场景故事让老板代入
⚠️ 不搞会怎样 → 显性+长期风险，日常语言，法条最多1条放括号
📖 真实案例 → 河南优先/全国知名案例，深度剖析(谁+干了啥+怎么被发现+罚多少+为什么你有关系)
📋 怎么搞 → 当下立刻做 + 长期制度建设
**我们能帮上：** → 一句话，不吹
💬 咨询师谈单话术 → 共情+逼单+价值塑造，嵌入每条风险内
```

### 绝对不写的承诺（用户多次纠正）
- ❌ "帮您换供应商"（本身有风险）
- ❌ "帮您代开发票"（违法违规）
- ❌ "帮您申请核定征收"（不做这种服务）
- ❌ "帮您对接银行/贷款额度提升XX倍"（不承诺做不到的事）
- ❌ "我方承担连带责任"（法律风险远超营销价值）
- ❌ "罚款减免XX%"的数字承诺（实务中幅度由税务机关裁量）

### 正确写法
- 能做什么：把风险梳理清楚、出方案、陪跑落地
- 不能做什么：不承诺风险为零、不承诺免除处罚、不承诺一定能解决
- 话术示例："我们能做的是帮您把真实的业务成本梳理清楚...我们陪您一步步来"

## 案例写作标准

每个案例必须包含（参考慕有枝案例库格式）：
1. 人物/企业名称 + 具体违规操作
2. 怎么被发现的（大数据/举报/关联案）
3. 处罚结果（追缴+滞纳金+罚款具体数字）
4. 后续影响（账户冻结、限高、失信、判刑）
5. 这个案例对读者有什么用

一句话带过的案例不写。参考标准：每个案例至少100-200字深度分析。

## 案例时效性规则（2026年6月确立）

税务处罚具有时效性。**只选用2025年1月1日之后的案例。** 2025年之前的处罚案例，处罚标准、稽查方式、社会环境都已变化，对当前业务参考价值很小。

案例搜索优先级：①河南本地税务稽查公示 → ②全国知名热点案件（范冰冰/薇娅/司马南/北大荒等）→ ③裁判文书网涉税案件。不编造案例。

## 文件名规则（2026年6月确立）

保存财税方案/案例/报告的Markdown文件时，**文件名必须用中文标题（经简单清洗去特殊字符），不能用数字ID或编号。** 数字ID不可记忆，后期无法通过文件名搜索定位。清洗规则：去除非中文字符/字母/数字/空格/连字符以外的字符，长度不超过50字。

## 话术嵌入规则（2026年6月确立）

咨询师谈单话术库不能单独放附录，必须嵌入每条风险条目的末尾。每段话术含：共情话术 + 逼单话术 + 价值塑造话术。与风险解析联动，便于理解和记忆。

## 双Agent审核标准

### Codex（硬伤审核）
- 法条引用是否准确（时效性、条款号）
- 数据是否自洽（金额计算逻辑）
- 合规建议是否有法律风险
- 32项是否完整无遗漏
- 是否有过度承诺/虚假承诺

### Claude（软伤审核）
- 语气是否对老板友好（不官僚、不讲课）
- 话术是否实用（咨询师能直接拿来用）
- 案例是否贴切、有深度
- 结构是否一致、清晰
- 是否有错别字、繁体字混入
