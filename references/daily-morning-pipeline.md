## 手动操作模式

### PDF 文件蒸馏
1. 提取全文内容 → 蒸馏结构化要点
2. 保存蒸馏稿到对应目录：财税政策→`01_财税/`，工作方法→`02_工作法/`，心法→`03_心法/`
3. **原文件移出Obsidian库** → `D:\财税法智库_源文件\PDF\`，不留在库内
4. 清理临时提取文件

### 网页链接（政策/税案/观点）
1. 提取全文
2. 判断类型归类：财税案例→`01_财税/综合案例/`，税案→`02_工作法/税务稽查应对/`，心法→`03_心法/`
3. 保存蒸馏稿
4. 税案/财税案例同时更新 `01_财税/最新案例速查.md`

### 河南12366热点问答
1. 提取全文，列出所有问答
2. 精简：去掉"变更办税人员"等每月重复的通用问答，只保留本期独特内容
3. 补充"本期最值得记住的3个知识点"
4. 保存到 `01_财税/法规政策/2026年M月河南12366热点问答_N题蒸馏.md`

## 飞书推送

- 每天 9:15 自动检查当天有无新入库内容
- 有 → 汇总成早报 → 用 lark-cli API 创建飞书文档 → 添加到知识库
- 无 → 安静结束

飞书推送工作不需要 gateway 的 `deliver` 机制，用 cron prompt 内的 lark-cli 命令直接操作。这样即使 gateway 没跑也能推送。
