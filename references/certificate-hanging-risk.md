# 证书挂靠风险 — 行业审计要点

## 触发条件
社保费本期发生额 ÷ 应付职工薪酬贷方（年化工资估算）> 1.5 且行业有持证要求

## 五大高风险行业

### 1. 检测服务（CMA/CNAS）
- 资质要求：CMA认证/CNAS认可，需配备持证检测人员
- 挂靠信号：社保人数远超工资人数
- 风险链：挂靠→虚列人工成本→所得税少缴→资质人员不达标→吊销

### 2. 建筑安装（建造师/施工资质）
- 资质要求：建造师、施工员、安全员等
- 挂靠信号：社保>工资，项目人员社保与项目地点不匹配
- 风险链：挂靠费私下支付→无发票→虚增利润

### 3. 设计院（注册建筑师/结构师）
- 资质要求：注册建筑师、注册结构师
- 挂靠信号：社保>工资，挂靠人员无实际考勤
- 风险链：高新/科小申报虚假→骗补风险

### 4. 医疗（执业医师/护士）
- 资质要求：执业医师、护士执业证
- 风险链：医疗许可证年检→吊销风险

### 5. 教育（教师资格证）
- 资质要求：教师资格证
- 风险链：办学许可证年检→吊销风险

## 追查路径
1. 计算社保/工资比 → 超1.5标记
2. 查企业信用公示系统 → 确认资质要求
3. 风鸟查企业工商信息 → 匹配人员名单
4. 追查挂靠费支付 → 是否入账、有无发票
5. 评估资质影响 → 高新/科小/专精特新申报真实性
