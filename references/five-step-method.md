## 五步出方案法

### 第零步：先判小微企业（强制执行，不可跳过）

**这是税务身份判定的前置步骤，在任何方案出具前强制执行，不可跳过。**

#### 小微企业335条件

同时满足以下三个条件即为小微企业：

| 条件 | 标准 | 说明 |
|------|------|------|
| 年应纳税所得额 | ≤ 300 万元 | 应税利润，不是营收 |
| 从业人数 | ≤ 300 人 | 含劳务派遣用工 |
| 资产总额 | ≤ 5,000 万元 | 资产负债表总资产 |

#### 税率适用

| 情形 | 税率 | 说明 |
|------|------|------|
| 小微企业 | **5%** 企业所得税 + 六税两费减半 | 默认税率 |
| 一般企业（不符合335） | 25% 企业所得税 | 非小微企业 |

#### 铁律

- **绝对禁止**用 25% 和 10% 计算税务敞口。小微企业的所得税率是 5%，不是 25%，也不是 10%。
- 六税两费减半同时适用：城建税、教育费附加、地方教育附加、印花税、房产税、城镇土地使用税。
- 判断不清时，先查企业最新季度所得税申报表或上年度汇算清缴数据，确认是否符合335条件。
- 对临界企业（所得接近300万、人数接近300人、资产接近5000万）要重点提示阈值风险：一旦超标次年失去优惠资格。

### 第一步：先确认关系

**合同签了没？钱收了没？服务期多长？这三个问题必须先问，决定整个对话的语气和框架。**

#### 三问自查表

| 问题 | 是 | 否 | 影响 |
|------|----|----|----|
| 合同已签？ | 进入交付模式 | 销售/谈单模式 | 决定话术是"展示价值"还是"开始干活" |
| 费用已收？ | 删除预算相关话术 | 需探询预算 | 已收款后不再谈"值不值" |
| 服务期确定？ | 制定工作计划 | 先确定服务范围 | 决定交付物的格式和深度 |

#### 姿态切换对照

| 维度 | 销售姿态（未签约前） | 服务交付姿态（已签约已收款） |
|------|----------------------|-------------------------------|
| 开场 | "问题出在管理上，不是账上"（给台阶） | "合同签了费收了，咱们是自己人"（直接干活） |
| 预算话题 | 需要专门探询 | **删掉**，钱已收 |
| 回避话题 | 有"第一次不谈"的红线 | 合同期内该谈就谈，没有禁区 |
| 交付物 | 需求确认函、报价方案 | 工作计划、模板、时间节点 |
| 节奏 | "先试试，慢慢来" | "12个月怎么排，第一季做什么" |

#### 已签约已收款后的行动

- 立即删除所有销售话术和探询预算的内容
- 直接切入：工作计划、时间节点、团队分工
- 交付姿态：专业、直接、结果导向
- 参考：`references/construction-engagement-framework.md`

### 第〇.五步：确认报告定位

**在开始写报告前，必须先确认本次出的是专业版还是融合版。**

#### 专业版 vs 融合版

| 维度 | 专业版 | 融合版 |
|------|--------|--------|
| 触发词 | "专业分析"/"纯技术" | "出方案"/默认 / "看人"/"人性" |
| 适用场景 | 内部审计、同行交流、纯技术问题 | 客户汇报、谈单、棘手客户 |
| 语言风格 | 法条、准则、底稿语言 | 先看局再看账、人性化表达 |
| 内容侧重 | 技术正确、专业深度 | 技术正确 + 政治可行 + 人性洞察 |
| 篇幅控制 | 精炼、直击要点 | 有血有肉、有步骤有台阶 |
| 交付物 | 审计底稿、技术备忘录 | 客户方案、谈单建议书、说辞 |

#### 判断标准

1. **看受众**：客户看？还是会计/财务经理看？
2. **看目的**：交付审计成果？还是推动客户变革？
3. **看关系**：已是客户（可谈深层）？还是潜在客户（先建立信任）？
4. **看场合**：正式汇报？内部讨论？初次接触？

> 核心原则：对客户永远优先选择融合版——技术正确不等于政治可行，客户不是法条，是活生生的人。

### 第二步：看人（不是看账）

**先搞清楚谁在这个局里，再翻开账本。三个问题先回答。**

#### 三个必答问题

1. **谁是决策者？**
   - 老板本人？职业经理人？财务负责人？
   - 决策风格：独断型？协商型？授权型？

2. **他关心什么？**
   - 赚钱/省钱/安全/面子/省心？
   - 当下最痛的点是什么？是税务压力？现金流？还是未来上市/融资？

3. **谁可能反对？**
   - 内部阻力：财务经理怕丢脸？业务部门怕麻烦？
   - 外部阻力：合伙人理念不合？家属干预？

#### 用老板痛点组织问询的对照表

| 老板痛点 | 专业翻译（❌ 别这么说） | 融合翻译（✅ 这么说） |
|----------|----------------------|-------------------|
| 税太重 | "企业所得税税率适用不当" | "你现在交的税，小微企业标准是5%，你按25%在交，一年白送几十万" |
| 现金流紧张 | "营运资金周转率偏低" | "钱在外面回不来，垫一个项目借一次钱，利息都能吃掉利润" |
| 管理混乱 | "内部控制缺失" | "财务就是记流水账，老板拍脑袋决策，项目赚没赚钱都算不清" |
| 怕查税 | "税务风险敞口较大" | "现在金税四期+大数据，以前那种做法最多再撑两三年" |
| 想扩张但没钱 | "融资能力受限" | "报表不好看，银行不批贷，连投标保证金都凑不齐" |
| 股份/传承问题 | "股权架构亟待优化" | "现在是一锅粥，哪天出点事，个人资产和公司资产全混在一起" |

#### 建筑行业特殊关注点

建筑行业座谈不能只從财务报表出发，必须从经营视角切入（参考 `references/construction-engagement-framework.md`）：

**五大板块、14个老板级问题：**

| 板块 | 编码 | 问题 |
|------|------|------|
| **A. 钱——现金流与资金效率** | A1 | 垫资压力：账上现金够撑几个项目的同时施工？ |
| | A2 | 银行授信：其他应收款（股东借款）有没有影响续贷？ |
| | A3 | 甲方拖欠：应收账款真实账龄？有没有走诉讼的？ |
| | A4 | 资金预算：每月能不能拿出一张"收多少、付多少、缺口多大"的表？ |
| **B. 利润——项目盈亏与报价能力** | B5 | 分项目利润：每个项目材料/人工/机械/利润能不能独立算清？ |
| | B6 | 费用归集：管理费里有没有本该进项目成本的钱？ |
| | B7 | 挂靠/合作：挂靠项目利润怎么处理？无成本票→25%所得税风险 |
| **C. 人——组织与配合** | B8 | 项目经理配合度：让他们每月多填一张表，阻力多大？ |
| | B9 | 包工头管理：用工风险（工伤/跑路）怎么隔离？ |
| | B10 | 采购制度：有没有比价？材料成本一年差300-600万 |
| **D. 合规——税务与法律** | B11 | 简易计税证据链：甲供材确认单齐不齐？ |
| | B12 | 老板个人风险隔离：个独/夫妻店模式下个人资产安全 |
| **E. 未来——增长与升级** | B13 | 资质升级：二级够不够？要不要冲一级？ |
| | B14 | 政策红利：高新/专精特新/研发加计扣除申请了吗？ |

### 第三步：找动力（不是找问题）

**找到问题只是起点，让老板愿意动手才是关键。把专业风险翻译成老板听得懂、有感觉的话。**

#### 翻译对照表

| 专业风险 | 老板听得懂的话 | 痛点映射 |
|----------|---------------|----------|
| 视同分红个税风险 | "股东借款挂在账上一年不还，税务局就当你分红，20%个税你交不交？" | 怕多交钱 |
| 虚开发票 | "上游开票公司要是跑路了，税务局第一个找你——你收到的票全变成废纸" | 怕连累 |
| 账外经营 | "银行流水随便拉一条，税务局就能顺藤摸瓜查出你少报的300万" | 怕暴露 |
| 社保不合规 | "员工一个工伤举报，社保局+税务局联合查你过去三年的社保记录" | 怕出事 |
| 内部控制缺失 | "项目经理自己找供应商自己报价，中间吃回扣你都不知道" | 怕被坑 |
| 股权架构问题 | "现在公司是你一个人的，哪天出事，房子车子全要赔进去" | 怕失去 |

#### 找动力的四个维度

1. **怕损失**（避害）：税务罚款、滞纳金、信用降级、老板个人资产牵连
2. **想得到**（趋利）：节税空间、融资能力、投标资格、政策红利
3. **要省心**（省力）：自动化流程、减少人为干预、降低管理成本
4. **求发展**（进取）：企业升级、资质提升、对接资本市场

> 每个方案至少覆盖两个维度，缺一不可。

### 第四步：设计能落地的路径

**方案写得再漂亮，落不了地就是废纸。能一次改完不要分三次，每步给台阶。**

#### 路径设计原则

1. **能一次改完不要分三次**
   - 减少客户执行成本
   - 减少沟通反复
   - 能合并的步骤绝不拆分

2. **每步给台阶**
   - 每个执行步骤都要有"退路"或"过渡方案"
   - 让老板有台阶下，让财务有面子
   - 不能只给"最好方案"，不给"可行方案"

3. **节奏要合理**
   - 按时间轴排列：立即能做的 → 本月能做的 → 本季度能做的
   - 每个步骤标注：谁做、做什么、需多长时间
   - 明确先决条件：A做完才能做B

4. **阻力预判**
   - 每个步骤标注可能的内部阻力
   - 提前给出化解方案

#### 落地路径模板

```
## 第一阶段：立即行动（本周）
- [具体动作1] —— 谁做、怎么做
- [具体动作2] —— 谁做、怎么做

## 第二阶段：稳步推进（本月）
- [具体动作3] —— 需要 ×× 配合
- [具体动作4] —— 给××台阶的说法

## 第三阶段：固化沉淀（本季度）
- [具体动作5] —— 形成制度
- [具体动作6] —— 验收标准
```

### 第五步：写有血有肉方案

**方案不是法条汇编，是给老板看的行动指南。5段式结构 + 给老板准备好的话。**

#### 5段式结构

| 段落 | 内容 | 篇幅建议 |
|------|------|----------|
| **一、看局** | 一两句点破人事格局，让老板觉得"这人懂我" | 1-2段 |
| **二、现状与痛点** | 用老板自己的话说出问题，不用专业术语 | 2-3段 |
| **三、路径与步骤** | 具体执行方案，有时间节点、有责任人 | 主体部分 |
| **四、风险与台阶** | 可能遇到的阻力和应对方案 | 1-2段 |
| **五、下一步** | 给老板准备好的话：可以直接拿去说的说辞 | 1段 |

#### 给老板准备好的话

每个方案末尾必须包含一段"给老板准备好的话"——老板可以直接拿去跟合伙人、管理层、财务经理说的原话。例如：

> **对合伙人说的：**
> "我找了××财税顾问来看了一下，他们说咱们现在这个做法，放在前十年没问题，但金税四期上线后风险太大了。他们给了个方案，前三个月先做最基础的两件事，不会影响正常经营。你看咱们什么时候安排一次碰头？"
>
> **对财务经理说的：**
> "××老师建议我们这几个科目要调整一下，不是说你做得不对，是现在的政策变了，相应的方法也要变。我约了他下周来跟你对一次，你把你手头的资料整理一下。"

### 32项风险方案 · 人性版格式（2026年6月新模板）

从本session实实践证明有效的模式。32项风险清单的每个条目统一使用以下结构：

## 【风险N】标题

🎯 **这事像什么**（一个老板代入的场景，用河南老板日常口吻）

⚠️ **不搞会怎样**（显性+长期风险，日常语言。法条最多1条，放括号里即可）

📖 **真实案例**（深度剖析：企业/人名+具体干了什么+怎么被发现的+罚了多少+为什么跟你有关系。案例必须有深度，不能一句话带过）

📋 **怎么搞**（当下就做的：2-3件本周能做的事；长期要做：制度层面；我们能帮上：推荐服务，如实说明能做什么不能做什么）

💬 **咨询师谈单话术**（共情话术+逼单话术+价值塑造话术三句话，紧跟在风险讲解后面）

**关键原则：**
1. **人话优先** — "说白了" "你肯定见过" "说句不好听的"这种朋友聊天口吻，不要写公文
2. **法条藏起来** — 最多1-2条，放括号里，不要单列一段吓老板
3. **案例要有分析** — 企业名+做了什么+怎么被发现的+罚了多少+为什么对你有用，至少100字，不能一句话带过
4. **不承诺做不到的事** — 绝不写"帮您换供应商"/"帮您代开发票"/"帮您申请核定征收"/"帮您对接银行"等虚假承诺。能做的是帮客户把风险梳理清楚、把合规路子铺好
5. **话术嵌入条目内** — 共情/逼单/价值塑造三句话紧跟在风险讲解后面，顾问看到讲解时话术就在旁边，不用翻附录
6. **每个风险配一个真实案例** — 优先河南本地→其次中原区域→最后全国典型案例（如范冰冰、薇娅等知名案件），不虚构案例
7. **河南本地案例全覆盖** — 案例地市要覆盖郑州、洛阳、新乡、安阳、南阳、开封、许昌、漯河、驻马店、商丘、周口、信阳、平顶山、鹤壁、焦作、濮阳、三门峡、滑县、临颍等

## 交付物三审制

> 出品方出初稿 → 我审 → 打回或放行 → 你看终稿

### 审核流程

```
┌──────────────┐
│  出品方出初稿  │   AI Agent / 团队成员
└──────┬───────┘
       ▼
┌──────────────┐
│   我审（一审）  │   融合视角负责人
└──────┬───────┘
       ▼
   ┌───┴───┐
   │ 打回   │ 放行
   └───┬───┘
       ▼
┌──────────────┐
│  你看终稿      │   最终用户（老板/客户）
└──────────────┘
```

### 审核清单7项

**每一个交付物在放出前必须逐项检查，缺一不可：**

| 序号 | 审核项 | 检查要点 | 典型问题 |
|------|--------|----------|----------|
| 1 | **事实错误** | 数据是否准确？法条是否适用？时间节点是否合理？ | 税率用错、金额对不上、引用废止法条 |
| 2 | **格式铁律** | 排版是否整洁？层级是否清晰？标题序号是否连贯？ | 乱码、层级混乱、用词不一致 |
| 3 | **客户画像** | 内容是否匹配该客户的行业、规模、痛点？ | 放之四海皆准的套话、不针对具体客户 |
| 4 | **行业联想** | 是否触发该行业的基础风险联想？建筑/检测/医疗等有特殊风险？ | 建筑行业没谈挂靠、检测行业没提设备折旧 |
| 5 | **技能完整性** | 方案是否覆盖了融合视角的各个维度？ | 只有专业没有人性、只有问题没有路径 |
| 6 | **读全文件** | 参考的行业报告、客户资料是否已全部阅读？ | 只看了一页就下结论 |
| 7 | **小微企业预检** | 第零步执行了没有？335条件判断了没有？ | 非小微按小微算、小微按一般企业算 |

## 三视角并行分析

**审计合规 / 税务稽查 / 客户沟通 三个子Agent并行分析，总控合并。**

### 机制说明

每次出具客户方案时，从三个平行视角同时分析，最后总控合并输出：

```
                    ┌────────────┐
                    │  总控合并    │  ← 融合视角负责人
                    └─────┬──────┘
                          │
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
   ┌────────────┐  ┌────────────┐  ┌────────────┐
   │ 审计合规视角  │  │ 税务稽查视角  │  │ 客户沟通视角  │
   ├────────────┤  ├────────────┤  ├────────────┤
   │ 准则要求     │  │ 稽查口径     │  │ 老板听得懂   │
   │ 底稿规范     │  │ 风险敞口     │  │ 有台阶能接受 │
   │ 证据链要求   │  │ 处罚标准     │  │ 执行阻力最小 │
   └────────────┘  └────────────┘  └────────────┘
```

### 各视角关注点

| 视角 | 核心问题 | 输出重点 |
|------|----------|----------|
| **审计合规** | 这事儿合不合准则？底稿能不能出去？ | 准则依据、审计调整建议、证据链要求 |
| **税务稽查** | 税务局会怎么看？最坏情况是什么？ | 税务风险等级、处罚金额测算、整改窗口期 |
| **客户沟通** | 老板能不能接受？要怎么跟他讲？ | 人性化表达、说服路径、阻力预判、台阶设计 |

### 合并原则

1. **审计合规是底线** — 技术不能错，底稿不能丢
2. **税务稽查是风险上限** — 给最坏情况做预案
3. **客户沟通是落地钥匙** — 客户不接受，前两个毫无意义

## 首次座谈避谈清单

> **已签约客户首次座谈时，以下话题不要主动提出。**

这些话题不是"不该谈"，而是"第一次不适合"。第一印象决定客户愿不愿意把你当自己人，而这些话题一开始提出来，会让客户觉得"你是来找事的，不是来帮忙的"。

| 序号 | 避谈话题 | 原因 | 什么时候可以谈 |
|------|---------|------|---------------|
| 1 | **挂靠清理** | 挂靠是建筑行业的生存方式，一上来就说"挂靠违法"等于打客户的脸 | 建立信任后，第2-3次座谈 |
| 2 | **两账合一** | 两套账是历史问题，客户自己心里有数，第一次提让人下不来台 | 等客户主动提起，或第2次座谈 |
| 3 | **社保基数调整** | 社保合规是敏感话题，直接影响员工到手收入和老板用人成本 | 先做完薪酬分析，再见机行事 |
| 4 | **历史体外项目** | 账外项目是老板的"家底"，第一次就查这个等于在查老板本人 | 业务关系牢固后，以"提升规范度"角度切入 |

### 首次座谈建议话题

- 了解公司业务模式、组织架构
- 了解老板的经营痛点和期望
- 展示专业能力和行业经验
- 确认工作计划和时间节点
- 建立信任关系

> 核心原则：**第一次座谈是建交，不是查账。**

## 看账查风险报告模板

### 标准结构

```
# 关于 [公司名称] 的财税风险诊断报告

## 一、基本信息
- 企业名称：
- 所属行业：
- 适用税率（是否小微企业）：
- 报告日期：
- 报告范围：

## 二、核心发现（按风险等级排列）

### [风险等级] 发现1：标题
- 现象描述：
- 风险分析：
- 法规依据：
- 影响金额估算：
- 整改建议：

### [风险等级] 发现2：标题
- ……（同上结构）

## 三、综合评估
- 整体风险等级：
- 最优先整改事项：
- 预期整改效果：

## 四、详细说明（附录）
- 每项风险的计算过程
- 参考的法律法规条文
- 支撑数据截图/表格
```

### 风险等级体系

| 等级 | 标记 | 含义 | 代表性问题 | 客户理解 |
|------|------|------|-----------|----------|
| **L1 — 重大** | 🔴 红色 | 即期财务损失或行政处罚 | 视同分红个税、虚开发票、账外经营 | "不改就会被罚" |
| **L2 — 较高** | 🟠 橙色 | 近中期（1年内）大概率转化为损失 | 毛利率异常、股东借款逾期、大额现金 | "不改早晚出事" |
| **L3 — 关注** | 🟡 黄色 | 需改善但无即期风险，有优化空间 | 应收账款管理、内控缺失、行业特有风险 | "改了好处多" |
| **L4 — 建议** | 🔵 蓝色 | 优化建议，非必须整改 | 政策红利未享受、流程可优化 | "顺手的事" |

### 写作铁律

1. **每个风险必须有数据支撑** — 不写"可能存在风险"，要写"其他应收款中股东借款余额87万，超1年未还"
2. **每个风险必须给数字** — 不是"影响较大"，是"按5%算，涉及企业所得税约4.35万元"
3. **每个风险必须给台阶** — 不是"你们做错了"，是"这是行业通病，很多企业都这样，现在改来得及"
4. **L1/L2风险必须有整改路径** — 不能只发现问题不给解法
5. **L3/L4风险可以只给建议** — 不需要强制整改
6. **报告开头必须有整体结论** — 先给客户一个总印象，再看细节
7. **专业术语必须翻译** — 第一次出现的术语后面用小括号附老板听得懂的说法
8. **格式铁律** — 标题层级统一（# → ## → ###）、项目符号统一（-）、数字对齐
9. **默认税率5%** — 除非确认不是小微企业，否则报告中所有税务计算按5%执行
10. **结论先行** — 每段第一句给出结论，后面跟支撑细节
