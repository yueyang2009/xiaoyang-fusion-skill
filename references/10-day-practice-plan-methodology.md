# 10天快速出栏·谈单训练手册制作方法论

> 2026-06-28 实战验证：融合19个skill，产出47KB/10天每日练习版谈单手册

## 触发条件

用户要求：谈单培训、快速上手、每日练习、闭关训练、快速出栏、10天计划等。

## 制作流程

### 第一步：盘点可用skill（10分钟）

列出所有与谈单/销售/沟通/人性/心态相关的skill：

```
基础层：卡内基(人性的弱点) + 卡内基(人性的优点) + 阿德勒
说服层：西奥迪尼(影响力) + 卡尼曼(思考快与慢) + 芒格(25种心理倾向)
策略层：王雩(销售思想体系) + 达利欧(原则) + 苏世民(经验与教训) + 左闲人(人性驱动)
心态层：冯唐(成事心法) + 曾国藩(结硬寨) + 戎震(狠人哲学)
专业层：慕有枝(税法视角) + 魏禾(稽查视角) + 郭延娇(价值匹配论)
哲学层：老子 + 毛选 + 王阳明 + 孙子
```

### 第二步：按场景分类提取（每个skill提取3-5个核心框架）

每个skill只取最核心的谈单转化用法，不追求全面。

提取模板：
```
skill名称 → 3个框架 → 每个框架配1条可直接用的谈单话术
```

### 第三步：设计10天难度递进（关键）

递进逻辑：

```
Day 1-2: 心态奠基（先治自己）
  1. 心态筑基（阿德勒·课题分离 + 卡内基·接受最坏 + 冯唐·九字真言）
  2. 人性解码（卡内基·自重感 + 芒格·25种心理倾向 + 郭延娇·价值匹配 + 左闲人·三维驱动）

Day 3-5: 技术打磨（练基本功）
  3. 上门准备（毛选·调查 + 王雩·高维打低维 + 苏世民·信息优势）
  4. 破冰建信（西奥迪尼·喜好/互惠/权威 + 卡内基·好感六法 + 王雩·十分钟征服）
  5. 需求挖掘（王雩·3P法则 + 达利欧·五步流程 + 卡内基·钓鱼思维）

Day 6-8: 临门一脚（练成交）
  6. 风险引爆（慕有枝·存量时代 + 魏禾·稽查视角 + 卡尼曼·损失厌恶）
  7. 报价与异议（卡尼曼·锚定 + 芒格·心理倾向 + 卡内基·异议处理）
  8. 临门一脚（西奥迪尼·稀缺/承诺一致/社会认同 + 王雩·信念第一）

Day 9-10: 复盘与综合
  9. 谈后复盘（冯唐·金线原理 + 达利欧·五步流程 + 曾国藩·结硬寨 + 芒格·检查清单）
  10. 综合实战（全流程模拟 + 检查清单）
```

### 第四步：每日三段式结构

每课固定三块：

```
🌅 晨读（15分钟）— 心法+框架+话术
🌤 午练（30分钟）— 填空式练习模板
🌙 晚复盘（10分钟）— 检查清单+一句话总结
```

### 第五步：双Agent对抗审核

出完终稿后必须并行调度Codex和Claude做对抗式审核：

- **Codex查硬伤**：术语准确性（如"卡里尔→卡瑞尔"）、附录与正文对齐、自洽性
- **Claude查软伤**：可执行性（无搭档版替代方案）、表达风格统一（口语化vs学术化）、进度跟踪

双方修复后合并，再推最终版。
