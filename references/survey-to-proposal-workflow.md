# 企业调研表→32项风险谈单方案 生成工作流

> 适用场景：客户填写了财税问题调研表（常见32项或类似清单），需要
> 1. 生成面向老板的风险深度解析方案
> 2. 同时用作内部咨询师培训教材
> 3. 注入河南本地真实稽查案例强化说服力
> 4. 植入高端财税服务推荐实现转化

## 标准流程

### 第一步：读取调研表

调研表通常是 docx 格式的表格，用 python-docx 读取：
```python
import docx
doc = docx.Document('调研表.docx')
for row in doc.tables[0].rows:
    cells = [c.text.strip() for c in row.cells]
```

提取后的32项风险分两类：
- **财税类：** AB账、个人卡、虚开发票、无票支出、存货不符等
- **经营股权类：** 股权架构、社保、资金效率、老板决策方式等

### 第二步：确定案例搜索方向

核心原则：**案例优先用河南本地，其次中原区域（山东/河北/山西），禁止使用南方案例。**

搜索来源：
- 河南省税务局官网「重大税收违法失信案件」公告
- 各地市税务局公示稽查案例
- 裁判文书网涉税案件（河南区域）
- 税屋网纳税评估案例

每条案例强制要素：`企业名称 + 属地 + 违规操作 + 偷税金额 + 最终追缴税款 + 滞纳金 + 罚款合计 + 后续影响`

### 第三步：并行生成

32项风险量大，拆成4路子Agent并行：

```
批1: 01-08（财税基础类）
批2: 09-16（发票/收入/资金类）
批3: 17-24（往来/股权/社保类）
批4: 25-32（综合/决策类）
```

### 第四步：每条风险三段式模板（V2人性版）

V1版太官味/太堆法条，老板抵触。2026年6月用户反复纠正后确立V2版：

```
## 【风险N】标题

🎯 这事像什么
[一个老板一看就能代入的场景/故事，用老板日常说话的口吻]

⚠️ 不搞会怎样
[显性+长期风险，日常语言说法条，最多1条放括号]
[法人/实控人/股东个人连带责任一句话列完]

📖 真实案例
[深度剖析：谁+干了啥+怎么被发现的+罚了多少+为什么跟你有关系]
[2025年1月1日之后的案例才有参考价值]

📋 怎么搞
**当下就做的：** 2-3件本周能做的事
**长期要做：** 制度层面
**我们能帮上：** 一句话推荐服务，不吹

💬 咨询师谈单话术
[共情话术] "……"
[逼单话术] "……"
[价值塑造话术] "……"
```

### 话术嵌入规则（2026年6月确立）

话术不能单独放附录，必须嵌入每条风险条目末尾。共情+逼单+价值塑造三段式，跟风险联动。不联动的内容学了也白学。

### V1→V2转换要点

| 问题 | V1（官方版） | V2（人性版） |
|------|-------------|-------------|
| 法条引用 | 每项3-5条 | 最多1条，放括号 |
| 开场 | 定性分析 | 场景故事（🎯这事像什么） |
| 案例 | 一句话带过 | 深度剖析（5个要素） |
| 策略 | 泛泛而谈 | 当下+长期可执行 |
| 话术 | 单独附录 | 嵌入每条末尾 |
| 承诺 | 写做不到的事 | 如实说明能做什么

### 第五步：合成 + 三个附录

- 附录一：32项风险分级清单（极高/高/一般）
- 附录二：咨询师谈单话术库（共情+逼单+价值塑造）
- 附录三：客户谈单使用指引

## 注意点
1. 案例尽量真实可溯源，标注案件号/处罚文号
2. 河南城市全覆盖：郑州/洛阳/新乡/安阳/南阳/开封/许昌/漯河/驻马店/商丘/周口等
3. 税法条款必须写明文号，不能说"相关税法规定"
4. 罚款区间、量刑标准必须量化
5. 每项末尾必须植入服务推荐
