# 行业风险自动联想矩阵

> **用途**：快速查阅各行业证书挂靠风险的特征信号、风险链路和检查要点。
> **详细说明**：参见 [certificate-hanging-risk.md](./certificate-hanging-risk.md) 获取更完整的追查路径与方法论。

---

## 通用判断规则

```
社保费本期发生额 ÷ 应付职工薪酬贷方（年化工资估算） > 1.5
且 行业存在持证要求
  → 大概率证书挂靠
  → 追查：挂靠费支付方式、资质合规性、所得税影响
```

---

## 1. 检测服务（CMA/CNAS 资质）

### 特征信号

- 社保缴费人数 ≥ 工资发放人数 × 1.5
- 检测人员持证数量与业务规模不匹配
- 社保基数异常高、工资基数异常低
- 频繁的人员变动记录（挂靠人员短期进出）

### 风险链路

```
社保 > 工资 1.5倍
  → 证书挂靠
  → 虚列人工成本（虚增费用）
  → 企业所得税少缴
  → 资质人员不达标
  → CMA/CNAS 吊销风险
```

### 检查要点

- [ ] 逐人对比社保缴纳名单与工资发放名单
- [ ] 核查检测报告签字人员是否在社保名单内
- [ ] 确认挂靠费是否通过"其他应付款"或"往来款"私下支付
- [ ] 评估虚列人工成本对所得税的影响金额
- [ ] 查验 CMA/CNAS 年检材料中人员名单的真实性

---

## 2. 建筑安装（施工资质 / 建造师）

### 特征信号

- 社保人数异常高于项目现场实际管理人员
- 建造师、安全员等持证人员不在项目驻地缴纳社保
- 企业支付大额"咨询费""劳务费"但无对应服务记录
- 项目人员社保缴纳地与项目所在地跨省/跨市

### 风险链路

```
社保 > 工资
  → 建造师挂靠
  → 挂靠费私下支付（无发票、不入账）
  → 虚增利润（费用未入账）
  → 企业所得税多缴（反向影响）
  → 项目人员社保不匹配
  → 施工资质动态核查不通过
```

> **注意**：挂靠费不入账会导致费用被低估、利润被高估，与虚列人工成本方向相反，需专项评估。

### 检查要点

- [ ] 获取建造师/中级以上职称人员名单，比对社保记录
- [ ] 核查项目现场实际管理人员与社保名单的匹配度
- [ ] 追查"挂靠费"支付渠道（个人账户转账、现金等）
- [ ] 评估社保异地缴纳对项目属地监管的风险
- [ ] 查验施工资质动态核查记录

---

## 3. 设计院（注册建筑师 / 结构师）

### 特征信号

- 注册人员社保在本单位但无实际考勤记录
- 注册人员同时出现在多家单位社保记录中
- 设计图纸签字人员与实际项目参与人不符
- 高新/科小申报中研发人员包含挂靠注册人员

### 风险链路

```
社保 > 工资
  → 注册师挂靠
  → 挂靠人员无实际考勤
  → 高新/科小申报中研发人员虚列
  → 高新资质 / 科小资质虚假申报
  → 骗补风险 + 税务稽查风险
```

### 检查要点

- [ ] 调取打卡/考勤记录，对比注册人员出勤率
- [ ] 核查高新/科小申报材料中研发人员名单与考勤、工资的一致性
- [ ] 追查注册师社保缴费基数与实际工资是否匹配
- [ ] 评估虚假高新申报已享受的税收优惠金额
- [ ] 查验设计图纸签字栏与实际社保人员的一致性

---

## 4. 医疗（执业医师 / 护士）

### 特征信号

- 医疗机构社保名单含大量"多点执业"但无实际排班
- 执业医师社保在本机构但从未出现门诊/手术记录
- 护士执业证注册人数远超实际在岗护士数
- 医疗许可证年检前后人员变动异常

### 风险链路

```
社保 > 工资
  → 医师挂靠
  → 医疗许可证年检材料虚假
  → 年检不通过
  → 医疗许可证吊销 / 停业整顿
```

### 检查要点

- [ ] 比对社保名单与门诊排班表、手术记录
- [ ] 核查多点执业备案是否在卫健委系统可查
- [ ] 追查挂靠医师是否收取"证件使用费"（私账收款）
- [ ] 评估医疗许可证年检中人员达标情况的真实性
- [ ] 查验医疗机构校验记录与处罚历史

---

## 5. 教育（教师资格证）

### 特征信号

- 培训机构/学校社保人数远多于实际授课教师
- 教师资格证注册地与实际教学地不一致
- 办学许可证申报材料中教师名单与社保不匹配
- 挂靠教师无实际课表或教学记录

### 风险链路

```
社保 > 工资
  → 教师挂靠
  → 办学许可证年检材料虚假
  → 年检不通过 / 被举报
  → 办学许可证吊销
```

### 检查要点

- [ ] 比对社保名单与课表安排、教学日志
- [ ] 核查教师资格证注册状态与所在单位是否一致
- [ ] 追查挂靠教师费用支付方式及是否入账
- [ ] 查验办学许可证年检材料、教师资质公示信息
- [ ] 评估无证教学/资质不达标对在校学生权益的影响
